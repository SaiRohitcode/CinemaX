# CinemaX - Movie Ticket Booking System

CinemaX is a full-stack movie ticket booking web application built using the MERN stack. The application allows users to browse movies, select theatres and shows, choose seats, and manage their bookings. An admin panel is provided to manage movies, theatres, screens, shows, and bookings.

## Features

### User
- User registration and login
- Browse movies
- View movie details
- Select language and movie date
- Select theatre and show time
- View available seats
- Select seats and view booking summary
- Book movie tickets
- View booking history
- Cancel bookings

### Admin
- Admin authentication
- Dashboard with application statistics
- Add, edit, and manage movies
- Set movie availability period
- Add and manage theatres
- Manage screens
- Configure seat layouts and seat prices
- Add and manage shows
- View and manage bookings
- Manage users
